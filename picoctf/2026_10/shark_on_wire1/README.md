## writeup

### 1
このファイルには2317個のパケットがあります。
プロトコルを調べると、主に、
・UDP：1140パケット
・TCP：22パケット
・その他
となっている。
ここで、UDPが多いなと気づきます。

ナノで最初にwiresharkでudpと絞ります。

### 2
UDPだけに絞ると、いろいろな通信があります。
例えば、
```python
10.0.0.2:5000 → 10.0.0.5:8990
10.0.0.9:5000 → 10.0.0.5:8990
10.0.0.2:5000 → 10.0.0.22:8990
...
```
などです。
つまり、UDPだからといって全部がflagというわけではなかった。

どのUDPが怪しいのか考える。

### 3
そこでWiresharkの
```udp.stream```を使います。
これは**同じ送信元・宛先のUDP通信をひとまとまりとして扱うための番号**です。
例えば、
```python
Stream 0
Stream 1
Stream 2
...
```
というように、それぞれ別の通信に分かれます。
ここで重要なのは、**Stream番号そのものには意味がないことです。**

### 4

```python
10.0.0.13:8888

```

そして、この通信には**19個のUDPパケット**があります。
ここでさらに中身を見ると、非常に特徴的です。
